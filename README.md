# Improved Metabolic Flux Estimations through Compositional Data Analysis

This repository consist of code to reproduce data and figures from the paper "Improved Metabolic Flux Estimations through Compositional Data Analysis"

The files "toy_network_emu.py" and "tca_cycle_emu.py" defines the emu algoritm for the two example networks Toy Network and TCA cycle. 
The files "toy_network.py" and "tca_cycle.py" runs the optimizations for the ground truth recovery and the sensitivity analysis.
The file "profile_likelihood.py" runs profile likelihood for both Toy network and TCA cycle. 
the file "ci_plot.ipynb" calculates the Fisher Information Matrix based confidence intervals and make the figure.
